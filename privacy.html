Privacy Policy

rclone-personal · Last updated: 18 September 2026

Summary

rclone-personal is a private, single-user tool. It is operated by one individual for their own use only. It has no other users, collects no analytics, and transmits no data to any third party.

Data accessed

When authorised, the application uses the Google Drive API to read and write files in the Google Drive account that granted the authorisation. It does this in order to synchronise personal documents between that account and the owner's own computer.

The application does not request or receive access to any other Google service.

Data storage

  • File contents are transferred directly between the owner's computer and Google's servers. They do not pass through any intermediate server.
  • The OAuth access and refresh tokens are stored locally in the rclone configuration file on the owner's computer. They are not transmitted anywhere else.
  • No database, log server, or remote storage is operated by this application.

Data sharing

No data is sold, shared, transferred, or disclosed to any third party for any purpose. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Because no data is collected or retained by the application, there is nothing to delete on its side. Authorisation can be withdrawn at any time at Google Account permissions, which immediately ends all access.

Contact

Questions about this policy can be sent to the address listed on the project's Google Cloud contact record.
