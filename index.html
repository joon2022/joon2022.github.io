rclone-personal

A personal, single-user backup utility.

What this is

rclone-personal is a private configuration of rclone, an open-source command-line file synchronisation tool. It is used by its owner to back up personal notes and documents from a local computer to that same person's own Google Drive account.

Who can use it

Only the owner. This is not a public service, it has no user accounts, and it is not distributed to anyone else. It exists solely so that its owner can authorise rclone against their own Google Drive using their own API credentials rather than shared ones.

What it accesses

  • Google Drive files belonging to the account that authorises it
  • Nothing else — no contacts, no mail, no calendar, no other account

Access can be revoked at any time from Google Account permissions.
